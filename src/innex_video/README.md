# innex_video

This package streams OAK camera video as H.264 `CompressedVideo` messages for
Foxglove. It requires the DepthAI v3 Python library. Install it with:

```sh
python3 -m pip install depthai --force-reinstall
```

See the [official DepthAI v3 installation guide](https://docs.luxonis.com/software-v3/depthai/#installation)
for other installation options.
